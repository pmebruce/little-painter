# 小小畫畫教室

iPad 優先的兒童繪畫學習 PWA，採奶油白、鼠尾草綠與深綠色的教室風格。

- iPad 橫向：教學、4:3 畫布、畫具三欄常駐；直向與手機版會重新排列。
- 六組練習：線條、形狀、小貓、火箭、恐龍、狐狸，共 22 個步驟。
- 逐筆動畫只顯示在示範層，不寫入孩子的作品；可重播或直接下筆中止。
- 點選朗讀或開啟自動朗讀。語音由裝置提供，優先使用繁體中文語音；聲音與口音依裝置可用聲音而定。
- 只用觸控筆模式會忽略手指繪圖。支援瀏覽器提供的筆壓，無法代替系統原生的手掌辨識。
- 自由玩畫簡化畫具並提供對稱創作；切回學習不清除畫作。
- 課程切換及清空前提供確認，收藏存在本機瀏覽器，最多 12 張；清除網站資料前請先下載 PNG。
- 作品匯出不含示範、描紅與網格輔助線。
- 感壓與觸控筆已做瀏覽器事件測試，實際 Apple Pencil 手感仍需在 iPad 驗證。

部署：https://pmebruce.github.io/little-painter/
