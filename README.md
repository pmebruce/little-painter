# 🎨 小畫家魔法學院 (Little Painter PWA)

專為兒童設計的互動繪畫技巧學習 Progressive Web App (PWA)，同時支援手機直向、平板橫向（iPad / Android 平板）與電腦瀏覽器，並具備離線快取與主畫面安裝能力。

## ✨ 核心功能

1. **📐 分步拆解教學（幾何圖形拆解法）**：內建「🐱 幾何小貓」、「🚀 太空火箭」、「🦕 微笑恐龍」、「🦊 森林狐狸」四組 4 步驟拆解課程，搭配可調透明度的洋蔥皮描紅輔助層與「✨ 提示」閃爍指引。
2. **🔍 網格觀察對照（九宮格空間比例法）**：一鍵切換九宮格參考線，訓練孩子觀察相對位置與比例。
3. **🦋 對稱魔法畫布**：支援「左右鏡像對稱」與「四向萬花筒對稱」，輕鬆畫出蝴蝶、雪花與對稱圖騰。
4. **🌈 三原色混色實驗室與魔法畫具箱**：內建紅、黃、藍、白互動混色器，以及鉛筆、麥克筆、水彩柔邊筆、彩虹魔法筆、星星印章筆與橡皮擦。
5. **🖼️ 本機作品集與 PNG 下載**：使用 `localStorage` 離線保存畫作，或一鍵匯出 PNG 圖檔。

## 🚀 部署至 GitHub Pages (`little-painter`)

將本壓縮包解壓縮後的所有檔案（`index.html`、`manifest.json`、`service-worker.js`、`icon.svg`、`icon-180.png`、`icon-192.png`、`icon-512.png`、`README.md`）上傳至 GitHub `little-painter` 儲存庫根目錄（`main` 分支），即可透過 `https://<你的帳號>.github.io/little-painter/` 線上使用並安裝至手機或平板主畫面。

畫布固定為 4:3，旋轉裝置保留比例與復原紀錄。混色為顏料教學示意。作品儲存在本機瀏覽器，清除網站資料前請先下載 PNG。
