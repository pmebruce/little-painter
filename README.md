# 小小畫家學堂 - 兒童繪畫學習 PWA

一個給小朋友學習簡單繪畫技巧的 Progressive Web App。

## 功能

- 自由繪畫（支援滑鼠與觸控）
- 多種顏色與筆刷大小
- 橡皮擦、復原、清除、保存圖片
- 5 個簡單課程：太陽、房子、小花、小貓、星星
  - 每個課程有參考圖與步驟說明
- 可安裝為 PWA（加入主畫面），支援離線使用

## 如何使用

1. 把整個 `little-artist` 資料夾部署到任何靜態網站主機（GitHub Pages、Netlify、Vercel 等）。
2. 用瀏覽器打開 `index.html`。
3. 建議用手機或平板測試觸控繪圖。
4. 在支援的瀏覽器（Chrome、Edge 等）可以「加入主畫面」。

## 本地測試

在資料夾內執行：

```bash
python -m http.server 8000
```

然後打開 http://localhost:8000

## 課程內容

- ☀️ 畫太陽
- 🏠 畫房子
- 🌸 畫小花
- 🐱 畫小貓
- ⭐ 畫星星

每個課程都有分步驟引導，適合 4-8 歲小朋友。

---

可以根據需求繼續擴充更多課程、加入聲音鼓勵、或更進階的繪圖工具。
